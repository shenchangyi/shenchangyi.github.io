# 青原山 · 立体山水与手绘路线修复

版本：2026-10-25 scene2。手机入口 preview.html；立体近览 near.html。

## 这次如何使用

- 打开画卷即显示“游客中心至阳明书院”参考路线；左侧“更换路线”或底栏“推荐路线”可选另外两条。
- 在全域手绘模式继续放大，超过原画适合显示的尺度后，自动转入同一平面坐标的三维地物细览。文字与图标仍保持屏幕上的清晰尺寸。
- 点“立体近览”，可用俯看、斜看、平移、转动观察。底部“看铺装 / 看屋檐 / 逛街巷 / 观水岸”直接到近景。三维页也可选择三条留存路线。
- 卫星对照使用同一 BD-09 范围；进入卫星模式回到适合该影像的缩放，保留视图中心。局部航拍画卷仍为风格样张，游线与三维请使用全域层。
- 保留逛小店、天气、节目、清晰图标、飞鸟及云雾。店铺与价格为演示，无支付。

## 本次修复与模型范围

标题继续使用 Zhi Mang Xing 书法体。原来的字体子集不含“山”；新增原字库的完整“青原山”子集 qingyuan-title.woff2，未自行拼造字形。

此前 near.html 只是栅格画卷加少量平面轮廓，不能增加近景真实细节。本次运行时改为独立几何场景，近景不依赖 ink-native.webp：36 个建筑体块、5 组影像判读道路、6 处水域、703 块广场铺装、8317 株风格化林木。建筑有墙面、坡屋顶、屋脊、檐口和台阶；水面使用程序水纹；树木有树干、树枝与多个立体树冠。林木按 110 像素网格分区，视锥裁剪，远近切换几何精度。数量是当前示意模型的对象数量，不是景区实测统计。

原始水墨画稿仍为 3620×1930 像素，不会凭空变成无限高清原图。近景更清楚来自新建的几何与程序纹理；细节造型尚不等同于实景精细复原。

## 坐标、来源与可信度

- 共用范围：BD-09 西 115.0244992、南 27.0482008、东 115.093489、北 27.0811433。
- 三维源数据 data/scene-plan.json 使用 2048×1092.2667 的北向上影像坐标。比例 .01875 模型单位/影像像素；Three.js x 向东、z 向南、y 向上。Blender 使用 x 向东、y 向北、z 向上。
- 道路、水岸、屋顶体块和广场位置来自项目已有百度卫星图的人工判读；影像留存日期 2026-10-22，实际拍摄日期未知。与画卷共用范围，不代表已经完成独立地面精度验收。
- 林木在判读林地区域布置，避开水体、道路、广场与建筑；不是逐棵树的实测坐标。铺装、屋檐与立面细节为设计示意。
- 建筑高度为示意参数。未编造山体高程；没有 DEM，因此底面仍是平面，体积来自建筑、树木、岸缘与铺装等地物。
- 三条参考路线是 2026-10-25 百度接口留存的 BD-09 路径：1312 米、676 米、1940 米。与影像判读道路分开保存，不把手绘道路当作可导航路网。尚未现场实走。
- 净居寺平台点与影像屋群存在约 323 米差异。模型展示影像屋群，导航仍沿平台原始坐标，不擅自移动导航终点。

## 工程与续作

scene-geometry.mjs：几何、材质、林木分区与细节等级。
scene-renderer.mjs：主画卷内自动接入的俯视三维细节层。
near-scene.mjs：可旋转的三维近览与路线、卫星对照。
data/scene-plan.json：可校对、可替换的平面地物数据。
制作源文件/build-scene-data.py：按影像判读生成数据。
制作源文件/build-qingyuan-scene.py：由同一平面数据制作 Blender 体块工程。
制作源文件/qingyuan-scene-3d.blend：可编辑工程，已重新打开验证。网页不下载这个文件，而以 Three.js 实例化方式生成同一平面布局及更细的程序屋檐、水纹。

周四补拍仍需：建筑各面与屋顶、入口实际位置、可辨尺度参照、路口与桥梁、广场铺装近照。若要真实起伏地形，另需可用 DEM / 测绘高程数据，普通航拍单张不能替代。原“调研资料索取清单_20261022.pdf”的 10 月 29 日版本已包含这些采集项。

实现参考：[Three.js InstancedMesh](https://threejs.org/docs/pages/InstancedMesh.html)、[Zhi Mang Xing](https://fonts.google.com/specimen/Zhi+Mang+Xing)。字体许可随包保留。场景没有把照片缺失处宣称为测绘复原。

## 验证与限制

自动检查：三维、卫星与路线坐标变换一致；源数据范围与未实测标记；模型有真实竖向体积；林木分区及近远细节切换；原导览、商品与路径用例。
浏览器检查：手机尺寸下默认路线、放大进入几何层、立体视角、建筑 / 铺装 / 水岸近景与卫星对照。实体 iPhone、Android、微信内置浏览器、低端设备持续帧率和现场定位尚未验证。
