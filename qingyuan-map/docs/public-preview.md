# 青原山手机导览公开预览

2026-10-25 高清路线与地物底模更新。手机入口 preview.html；模型近览 near.html。

地图按屏幕像素绘制，可见区域加载无损原生图块；文字、图标和路线为独立矢量。原画3620×1930像素，近距离真实纹理细节仍受原图限制。

推荐路线可选择三条2026-10-25百度接口留存路径，直接显示在手绘中：游客中心至阳明书院1312米；阳明书院至动物园676米；游客中心至净居寺平台点1940米。均为BD-09、未现场实走的参考路径；不是实时导航。路径来源与获取日期保存在data/walking-reference.json。任意目的地导航继续打开百度地图；静态站不含服务端AK或设备坐标换算代理。

模型近览通过Three.js 0.180.0加载Blender导出的GLB，只包含影像描摹水域、参考道路和广场轮廓。是平面地物底模，没有实测建筑高度或山体海拔。几何放大仍清晰，栅格原画不能无限变清楚。建筑资料待10月29日调研补拍。

逛小店、天气、节目、DIY、飞鸟云雾保留。店铺/价格/商品为演示，不收款。节目按日期区分；天气来自Open-Meteo，依赖网络与服务可用性。

手绘与卫星共用范围和视角。影像为项目已有的2026-10-22留存图，拍摄日期未知；艺术化浏览图尚未完成独立地面精度验收。净居寺平台点和画稿屋群位置有差异，不能直接移动导航终点。
